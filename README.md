# 🍕 NORTHSIDE PIZZA Ver.49 — PWA ＋ みんなの日商ランキング

**Ver.48.1のゲームバランスをそのままに、無料PWAとオンラインランキングを追加した公開用セットです。**

- 🍕 スタッフなし・まとめ注文・注文ラッシュ・食材原価22%／改装後19%・LV100以降の高額設備はVer.48.1と同じです。
- 🏆 全体ランキング＋レベル別（LV1〜30／31〜60／61〜90／91〜100）のTOP50、正確な「自分の順位」を表示します。
- 🧑‍🍳 ニックネームは16文字まで。**名前登録後は閉店時の記録を自動投稿**し、各部門はその人の最高日商だけ掲載します。
- 📲 iPhoneのホーム画面に追加、オフラインでゲームを起動。**ランキングの送受信だけはインターネットが必要**です。
- 💾 従来のセーブ形式を維持。同じURL・同じブラウザ保存領域なら、原則として続きからプレイできます。

## 重要：このZIPだけではオンライン対戦はまだ始まりません

GitHub Pagesはゲームを公開する場所であり、みんなの記録を保存するデータベースではありません。そこで**無料枠のあるSupabase**を使います。

公開者が1回だけSupabaseの設定を終えれば、**遊ぶ人はSupabaseもGitHubも登録不要**。ゲームのURLを開いて、ゲーム内でニックネームを決めればランキングに参加できます。

### 必要なもの

- GitHubの無料アカウント（ゲームの公開用）
- Supabaseの無料アカウント（共有ランキングの保存用）
- iPhoneのSafariと「ファイル」アプリ（Mac不要）

## A. GitHub Pagesでゲームを公開する（iPhone）

1. ZIPをiPhoneで保存し、「ファイル」アプリでZIPをタップして**解凍**します。
2. Safariで https://github.com/new を開き、Repository name を `northside-pizza`、Visibilityを **Public** にして **Create repository**。
3. 作成したリポジトリの **Add file → Upload files**（最初の画面は **uploading an existing file**）を開きます。
4. **解凍したファイル**を複数選択してアップロードし、**Commit changes**。ファイルの一覧で `index.html`、`sw.js`、`leaderboard.js`、`leaderboard-config.js`、`manifest.webmanifest`、画像ファイルなどがすべて**同じ階層**にあるか確認します。 `README.md` や `supabase_setup.sql` はアップロードしても問題ありません。
5. **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**。
6. 数分後、同じPages画面の **Visit site** から起動。URL例：`https://あなたのユーザー名.github.io/northside-pizza/`

⚠️ ZIPをそのままアップロードしても動きません。**必ず解凍したファイルをアップロード**してください。Safariで編集ボタンなどが見えない場合は「デスクトップ用Webサイトを表示」を試します。

### 既に旧版を公開済みなら

1. ゲームで「セーブ・復元」からバックアップを保存します。
2. **同じGitHubリポジトリと同じURL**を使い、Ver.49のファイルで置き換えます。
3. Ver.49の `index.html` と `sw.js` を両方更新してください。古い画面が続く場合は通信できる状態で再読み込みし、ホーム画面アプリをいったん終了して開き直します。
4. 保存データは同一の保存領域なら維持されますが、Safari版とホーム画面アプリ版、または `file://` で開いたHTML版と公開URL版は別の保存領域になりえます。必要に応じてバックアップを復元してください。

## B. Supabaseに無料ランキングを作る（iPhone）

1. Safariで https://supabase.com/dashboard を開き、無料アカウントに登録します。
2. **New project** をタップし、名前（例 `northside-pizza`）・データベースパスワード・リージョンを設定します。**Freeプラン**を選んで作成します。
3. プロジェクト内の **SQL Editor → New query** を開きます。
4. 同梱の **`supabase_setup.sql` の全文**をSQL欄に貼り付け、**Run** を1回押します。これでテーブル、参照権限、投稿用の安全な関数を作成します。
5. **Authentication → Settings / Providers** などの認証設定で **Allow anonymous sign-ins**（匿名サインイン）を **ON** にします。画面の名称や場所は変更される場合があります。
6. プロジェクトの **Connect** または **Settings → API Keys** で、次の2点を確認します。
   - **Project URL**：`https://abcdefghijk.supabase.co` のようなURL
   - **Publishable key**：`sb_publishable_...` で始まる公開用キー
7. GitHubのリポジトリに戻り、`leaderboard-config.js` を開いて、**鉛筆アイコン（Edit file）**から下記2つの引用符の中身を入力して **Commit changes**。

```javascript
window.NSP_LEADERBOARD_CONFIG = {
  url: "https://あなたのプロジェクト.supabase.co",
  publishableKey: "sb_publishable_あなたの公開キー"
};
```

8. 少ししてから公開されたゲームURLを開き、「🌎 みんなの最高日商ランキング」を押します。「準備中」が消えてランキング画面を読み込めたら接続完了。
9. ニックネームを入れて「記録を投稿」を押し、営業を1日終えて記録が載るか確認します。別のブラウザからURLを開くと、複数人で記録を共有できることを確かめられます。

### セキュリティ上の重要な注意

- **Publishable keyだけを使用**してください。これはフロントエンド公開用として設計されたキーです。
- **`sb_secret_...`、`service_role`キー、データベースパスワードはGitHubに絶対にアップロードしないでください。**
- `supabase_setup.sql` ではテーブルへの直接的な書き込みを公開していません。投稿は本人の匿名認証トークン＋指定関数を経由します。
- ただし、**ブラウザ内で動くゲームなので、改造・偽装した高スコアを技術的に完全防止することはできません**。公開初期は友達同士の参考ランキングとして運用し、不審な記録はSupabase管理画面で削除してください。
- 匿名ユーザーを大量に作る悪用への対策として、Supabase公式はCAPTCHAなどの導入を推奨しています。利用者が増えたら検討してください（このキットはCAPTCHA未実装）。

## C. みんなが遊ぶ方法

1. 友達にGitHub Pagesの公開URLを送ります。**友達はアカウント不要**です。
2. ピザを作り、閉店で最高日商を記録します。
3. 「🌎 みんなの最高日商ランキング」を開いてニックネームを登録すると、自分のその時点の最高日商を投稿できます。
4. 以後は閉店時に記録が送信されます。ネット接続がなければ端末内で送信待ちとなり、次のランキング表示時などに再送します。
5. 同じ人が複数回投稿しても、全体と各レベル帯で**最高日商の1件だけ**が残ります。
6. iPhoneなら Safariの共有メニュー →「ホーム画面に追加」→「Webアプリとして開く」→「追加」でアプリ風に起動できます。

## D. よくある疑問

**Q: ゲームが無料なのは確か？**

GitHub PagesとSupabaseのFreeプランを利用範囲内で使えば0円です。ただしSupabaseには保存容量・通信量などの無料枠があり、アクセス増加時の制限や、長期間の未使用でのプロジェクト一時停止があります。有料プランを選ばなければ自動的に有料公開になるわけではありません。利用規約・料金表も確認してください。

**Q: レベル100の人がいつも上位では？**

全体順位は高レベルの方が有利なため、LV1〜30／31〜60／61〜90／91〜100の部門別順位も用意しました。

**Q: 最初に登録した前のバージョンの記録は？**

ニックネーム登録時に端末に残る最高日商を1件送信対象とします。旧記録に当時のレベルが保存されていない場合は**現在のレベル**で分類される点に注意してください。

**Q: iPhoneから別のiPhoneへ移したら順位は？**

ゲームのセーブはバックアップで移せますが、オンラインランキングの匿名ユーザーIDは別端末で引き継がれず、別のプレイヤーとして扱われます。またWebサイトデータを削除するとランキングに投稿した元の匿名アカウントへ戻れない場合があります。

**Q: 個人情報は公開される？**

ランキングには自分で入力したニックネーム、最高日商、店舗レベル、営業日数、匿名のプレイヤー識別子が保存されます。ゲーム内では本名・電話番号・住所を入力しないでください。管理者は公開前に必要に応じてプライバシー案内を設置してください。

**Q: GitHub上で隠し要素がバレる？**

Publicリポジトリのソースコードは閲覧できます。ゲーム画面では従来どおり解放前に隠していますが、コードの解析まで防ぐことはできません。
